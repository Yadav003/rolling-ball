# PlayArena Rolling Ball

Phase 1 basic playable prototype.

## Current features

- Automatic forward movement
- Left/right keyboard controls
- Mobile left/right controls
- Perspective-style track
- Custom SVG ball
- Custom SVG sky background
- Track boundary/fall detection
- Game-over screen
- Restart
- Distance and best-distance HUD

## Controls

Desktop:
- A / Left Arrow = left
- D / Right Arrow = right

Mobile:
- Use the left/right buttons.

## Phase 1 intentionally does NOT include

- Obstacles
- Coins
- Checkpoints
- Rewards
- Multiple levels
- Advanced physics
- Audio
- Complex UI

Those should be added only in later phases.

## Running

Because this project loads SVG assets, run it through a local web server instead of opening index.html directly.

For example, with VS Code Live Server:

1. Open this folder.
2. Right-click `index.html`.
3. Choose "Open with Live Server".
